# 错题集

## 使用约定

1. 每道做错的题收录到对应科目目录，文件名为可读的短标题。
2. 每条错题必须包含：题干、我的答案、正确答案、根因分析、完整知识点梳理。
3. **每道（每类）错题必须配套 5 道以上练习题**（举一反三），并同步生成艾宾浩斯复习题。
4. 目录结构按科目分类：数据结构、计算机组成原理、操作系统、计算机网络。

## 双通道刷题机制

| 端口 | 用途 | 题目来源 |
| --- | --- | --- |
| **4317** | 新错题当时练习 | 你刚发来的错题（即时生成） |
| **4318** | 艾宾浩斯到期复习 | 历史所有错题按遗忘曲线调度 |

**流程约定**：以后每收到一道新错题，必须同时做两件事——
1. 生成 5 道左右练习题到 **4317**，让你马上巩固；
2. 按「每类错题 5 题」的标准生成第 1 轮复习题，加入 **4318** 的艾宾浩斯队列（首学次日到期）。

## 艾宾浩斯复习机制

| 轮次 | 间隔 | 说明 |
| --- | --- | --- |
| 第 1 轮 | 首学后 1 天 | 短期记忆固化 |
| 第 2 轮 | 上一轮对后 2 天 | 中期记忆 |
| 第 3 轮 | 上一轮对后 4 天 | 抵抗快速遗忘 |
| 第 4 轮 | 上一轮对后 7 天 | 转入长期记忆 |
| 第 5 轮 | 上一轮对后 15 天 | 长期校验 |
| 第 6 轮 | 上一轮对后 30 天 | 终验，通过后归档「已掌握」 |

### 规则

1. 每轮复习使用**不同措辞、不同角度**的新题，避免背答案。
2. 任一轮答错：该知识点重置，回到「1 天后」重新开始。
3. 连续两轮全对且跨间隔 ≥ 7 天，才可标记「已掌握」。
4. 4318 页面只显示**今天到期**的知识点，未到期不出现。

## 目录结构

```
错题集/
├── README.md                 # 本文件
├── 数据结构/                  # 错题归档（按科目）
├── 计算机网络/
├── 计算机组成原理/
├── 操作系统/
├── quiz/                     # 4317 新错题练习页
│   ├── index.html
│   ├── questions.json        # 当前错题的即时练习题
│   ├── results.json          # 作答记录
│   └── server.js
├── ebbinghaus/               # 4318 艾宾浩斯复习页
│   ├── index.html
│   ├── questions.json        # 计算机网络复习题库
│   ├── ds-questions.json     # 数据结构复习题库
│   ├── queue.json            # 复习队列（到期日、轮次、记录）
│   ├── state.json            # 每轮作答状态
│   └── server.js
├── tests/                    # 结构校验测试
└── doc/sessions/             # 会话总结
```

## 运行

```bash
# 新错题练习（4317）
node 错题集/quiz/server.js

# 艾宾浩斯复习（4318）
node 错题集/ebbinghaus/server.js
```
