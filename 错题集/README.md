# 错题集

## 使用约定

1. 每道做错的题收录到对应科目目录，文件名为可读的短标题。
2. 每条错题必须包含：题干、我的答案、正确答案、根因分析、完整知识点梳理。
3. 学习完成后，追加 5 道举一反三练习题；如能对应历年真题，再补充 3-5 道类似真题。
4. 目录结构按科目分类：数据结构、计算机组成原理、操作系统、计算机网络。

## 复习机制（艾宾浩斯遗忘曲线）

错题不做「当天连刷」，而是按遗忘节点安排间隔复习：

| 轮次 | 时间点 | 目的 |
| --- | --- | --- |
| 第 1 次复习 | 错题当天稍后（首次学习后 20 分钟～1 小时） | 短期记忆固化 |
| 第 2 次复习 | 1 天后 | 巩固Day 1记忆 |
| 第 3 次复习 | 2 天后 | 进入中期记忆 |
| 第 4 次复习 | 4 天后 | 抵抗快速遗忘 |
| 第 5 次复习 | 7 天后 | 转入长期记忆 |
| 第 6 次复习 | 15 天后 | 长期记忆校验 |
| 第 7 次复习 | 30 天后 | 终验，通过后归档为「已掌握」 |

### 规则

1. 每轮复刷使用**不同措辞、不同角度**的新题，不重复原题，避免背答案。
2. 任一轮答错：该轮时间点重置，从「1 天后」重新开始计数。
3. 连续两轮全对且跨间隔 ≥ 7 天，才可标记「已掌握」。
4. 错题文件「复习记录」中逐轮登记：日期、轮次、题号、对错。
5. 在线题库只放**当前到期**的复习题，未到期的题不出现。
