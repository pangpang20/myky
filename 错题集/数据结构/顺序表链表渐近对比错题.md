# 顺序表与链表渐近对比错题

## 错题信息

- 科目：数据结构
- 章节：第 2 章 线性表
- 收录日期：2026-11-14
- 我的答案：C（Ⅰ、Ⅱ）
- 正确答案：A（仅Ⅰ）
- 状态：待复刷（艾宾浩斯第 1 轮）

## 题目

```
设 n≥4，只比较随 n 增长的最坏渐进时间复杂度，不比较常数因子。链表指仅保存头指针的普通单链表；Ⅰ 中的 i 是任意合法位序。下列哪些操作在顺序表上的渐近时间优于链表？
Ⅰ. 输出第 i（1≤i≤n）个元素值。
Ⅱ. 交换第 3 个元素与第 4 个元素的值。
Ⅲ. 顺序输出全部 n 个元素的值。
```

A. Ⅰ　B. Ⅰ、Ⅲ　C. Ⅰ、Ⅱ　D. Ⅱ、Ⅲ

## 根因分析

我把 Ⅱ（交换第 3、4 个元素）也算成「顺序表更优」，误以为链表要遍历。但 3 和 4 是**固定常数位序**：单链表从头指针走 3 步就到，仍是 O(1)，与顺序表**同阶**，不构成「渐近更优」。题干还特别强调「只比较随 n 增长的最坏渐进复杂度，不比较常数因子」——正是针对这个陷阱。

## 完整知识点梳理

| 操作 | 顺序表 | 单链表（仅头指针） | 顺序表是否更优 |
| --- | --- | --- | --- |
| 输出第 i 个元素（i 任意） | O(1) 下标直达 | O(n) 从头遍历 | **是** |
| 交换第 3、4 个元素 | O(1) | O(1)（固定 3 步） | 否（同阶） |
| 顺序输出全部 n 个 | O(n) | O(n) | 否（同阶） |
| 按值查找 | O(n) | O(n) | 否 |
| 表尾插入（无尾指针） | O(1)（均摊） | O(n) | 是 |
| 已知位置插入/删除 | O(n) 移动元素 | O(1) 改指针 | 否（链表更优） |

**关键判定法则**：
1. 位序是**变量 i** → 链表需遍历，顺序表 O(1)，顺序表优。
2. 位序是**常数**（第 3 个、第 4 个）→ 链表也只需常数步，两者同阶。
3. 「输出全部元素」两边都必须访问 n 个元素 → 同阶 O(n)。
4. 判断「更优」必须比较**关于 n 的阶**，常数因子与固定步数不算。

**记忆口诀**：

> **「变量位序看阶差，常数位序一样快」**——i 是变量顺序表赢，写死下标谁都不输。

## 复刷清单

### 举一反三 5 题

1. 【单选】下列操作在顺序表上比单链表（仅头指针）渐近更快的是（ ）。
   A. 输出第 i 个元素（i 为任意合法位序）　B. 输出第 1 个元素　C. 输出全部元素　D. 交换第 1、2 个元素
   **答案：A**。只有变量位序才产生 O(1) vs O(n) 的阶差。

2. 【单选】交换单链表中第 2 个与第 5 个元素的值，时间复杂度是（ ）。
   A. O(1)　B. O(log n)　C. O(n)　D. O(n²)
   **答案：A**。位序为常数，走固定步数即可。

3. 【单选】在顺序表上顺序输出全部 n 个元素的时间复杂度是（ ）。
   A. O(1)　B. O(log n)　C. O(n)　D. O(n²)
   **答案：C**。必须访问每个元素。

4. 【单选】设单链表仅保存头指针，删除表尾元素的时间复杂度是（ ）。
   A. O(1)　B. O(n)　C. O(n log n)　D. O(n²)
   **答案：B**。需遍历到倒数第二个结点。

5. 【单选】下列关于顺序表与链表的说法，正确的是（ ）。
   A. 顺序表所有操作都快于链表
   B. 位序为常数时，链表按位访问与顺序表同阶
   C. 链表随机存取效率高于顺序表
   D. 顺序表插入删除总比链表快
   **答案：B**。常数位序不产生阶差。

### 历年真题风格练习

1. 【统考风格】设 n≥4，只比较渐进复杂度。下列操作在顺序表上优于单链表（仅头指针）的是（ ）。
   Ⅰ. 取第 i 个元素（i 任意）　Ⅱ. 取第 1 个元素　Ⅲ. 取最后一个元素
   A. 仅Ⅰ　B. Ⅰ、Ⅱ　C. Ⅰ、Ⅲ　D. Ⅱ、Ⅲ
   **答案：C**。取第 1 个两边都 O(1)；取最后一个是 O(1) vs O(n)，顺序表优。

2. 【统考风格】下列关于「顺序表 vs 链表」的叙述，错误的是（ ）。
   A. 顺序表支持随机存取
   B. 链表在已知结点后插入是 O(1)
   C. 顺序表在任何按位访问上都优于链表
   D. 链表存储密度低于顺序表
   **答案：C**。常数位序时两者同阶。

3. 【统考风格】顺序输出 n 个元素，顺序表与单链表的复杂度关系是（ ）。
   A. 顺序表 O(n)，链表 O(n²)
   B. 顺序表 O(1)，链表 O(n)
   C. 两者都是 O(n)
   D. 两者都是 O(1)
   **答案：C**。都必须遍历全部元素。
