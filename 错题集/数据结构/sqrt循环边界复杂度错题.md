## 题目

设 n 为正整数，sqrt(n) 按常数时间计算。下列程序段的时间复杂度是（ ）。

```c
for (i = 0; i <= sqrt(n); i++)
    count++;
```

## 根因分析

我把「sqrt(n)」看成了「对数级别」的计算量，忽略了 sqrt(n) 循环边界本质上是一个**多项式级别的边界**——循环执行次数等于 sqrt(n)+1 次，量级为 O(n^(1/2))，而不是 O(log₂ n)。对数复杂度只出现在「每步把规模缩小一个常数因子」（如 i = i*2、i = i/2）的循环中，而这里是线性步长 i++，只是**终止条件**用了 sqrt(n)。

## 完整知识点梳理

| 循环形式 | 执行次数 | 复杂度 |
| --- | --- | --- |
| `i < n; i++` | n 次 | O(n) |
| `i <= sqrt(n); i++` | √n + 1 次 | **O(n^(1/2))** |
| `i <= n^k; i++` | n^k 次 | O(n^k) |
| `i < n; i *= 2` | log₂n 次 | O(log n) |
| `i < n; i = i*i` | log log n 次 | O(log log n) |

**关键判定法则**：
1. 步长不变（i++ / i--）→ 看边界，边界是 n^k 就是 O(n^k)。
2. 步长倍增/减半（i *= 2 / i /= 2）→ O(log n)。
3. 步长平方增长（i = i*i）→ O(log log n)。
4. sqrt(n) 本质是 n^(1/2)，属于多项式家族，不是对数家族。

## 记忆口诀

> **「边界定次数，步长定家族」**——步长不变看边界（√n 就是 √n 次），步长倍增才进对数家族。

## 复刷清单

### 举一反三 5 题

1. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 0; i <= n*n; i++) count++;
   ```
   A. O(n)　B. O(n²)　C. O(log n)　D. O(n log n)
   **答案：B**。步长不变，边界 n²，执行 n²+1 次。

2. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 0; i <= n/2; i++) count++;
   ```
   A. O(n)　B. O(n/2)　C. O(log n)　D. O(n^(1/2))
   **答案：A**。n/2 与 n 同阶，常数系数不影响量级。

3. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   i = n;
   while (i > 0) i = i / 3;
   ```
   A. O(n)　B. O(log₃n)　C. O(n^(1/3))　D. O(n log n)
   **答案：B**。步长每次除以 3，属对数家族，底数不影响量级。

4. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 0; i*i*i < n; i++) count++;
   ```
   A. O(n)　B. O(n^(1/2))　C. O(n^(1/3))　D. O(log n)
   **答案：C**。循环终止时 i ≈ n^(1/3)，执行 n^(1/3) 次。

5. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= log₂n; i++) count++;
   ```
   A. O(log n)　B. O(n)　C. O(n^(1/2))　D. O(log log n)
   **答案：A**。步长不变，边界 log₂n，执行 log₂n+1 次。注意：这里边界是对数，所以结果才是对数——判定依据是边界，不是直觉。

### 历年真题风格练习

1. 【统考风格】设 n 为正整数，下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 0; i <= sqrt(n) + 5; i++) count++;
   ```
   A. O(sqrt(n))　B. O(n)　C. O(log n)　D. O(sqrt(n) × log n)
   **答案：A**。边界 sqrt(n)+5 与 sqrt(n) 同阶，步长不变，执行约 sqrt(n) 次。

2. 【统考风格】若把题中的循环体改为「内层再嵌套一个 n 次循环」，整体时间复杂度变为（ ）。
   A. O(sqrt(n))　B. O(n)　C. O(n × sqrt(n))　D. O(n²)
   **答案：C**。外层 sqrt(n) 次 × 内层 n 次 = n × sqrt(n) = n^(3/2)，选项 C 与之一致。

3. 【统考风格】下列关于循环复杂度判定的说法，正确的是（ ）。
   A. 只要边界含 sqrt 或 log，就一定是对数复杂度
   B. 步长不变时，循环次数由边界决定；sqrt(n) 属多项式家族，不是对数家族
   C. 步长倍增与步长不变的复杂度判定完全一致
   D. 循环体语句越多，复杂度越高
   **答案：B**。判定分两步：先看步长（决定家族），再看边界（决定次数）。sqrt(n) 是 n^(1/2)，属多项式。
