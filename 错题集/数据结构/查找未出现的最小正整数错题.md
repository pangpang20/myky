## 题目

```
给定一个含 n(n≥1) 个整数的数组，请设计一个在时间上尽可能高效的算法，
找出数组中未出现的最小正整数。例如，数组 {-5, 3, 2, 3} 中未出现的
最小正整数是 1；数组 {1, 2, 3} 中未出现的最小正整数是 4。
要求：
(1) 给出算法的基本设计思想。
(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
(3) 说明算法的时间复杂度和空间复杂度。
```

（算法设计题，无选项。这是 2018 年统考真题 41 题。）

## 基本设计思想

**关键观察**：长度为 n 的数组中，答案一定落在 `1 ~ n+1` 之间。

- 最好情况：数组恰好包含 `1, 2, …, n`（顺序无所谓），答案为 `n+1`。
- 否则 `1 ~ n` 中必有某个正整数未出现，答案就是其中最小的那个。

因此不需要对数组排序，也不需要处理大于 n 的数（它们对答案无影响），只需**一趟扫描 + 一趟标记数组检查**：

1. 分配一个长度为 `n+1` 的标记数组 `B`（下标 `1 ~ n`，全部初值 0），`B[i] = 1` 表示正整数 `i` 在数组中出现过。
2. 扫描原数组一次：对每个元素 `A[i]`，若 `1 ≤ A[i] ≤ n`，则令 `B[A[i]] = 1`；小于 1 或大于 n 的数直接忽略（大于 n 的正整数不可能成为「未出现的最小正整数」——因为 `1 ~ n` 中必有缺口，答案轮不到它）。
3. 从 `i = 1` 到 `n` 检查 `B[i]`，第一个满足 `B[i] == 0` 的 `i` 就是答案。
4. 若 `1 ~ n` 全部出现，返回 `n + 1`。

**为什么答案不超过 n+1**：数组只有 n 个元素。若答案 > n+1，则 `1 ~ n+1` 至少 n+1 个数都出现过，至少需要 n+1 个数组元素，矛盾。

## 参考算法（C）

```c
int findMissMin(int A[], int n) {
    int i;
    int *B = (int *)malloc((n + 1) * sizeof(int));  // 标记数组，下标 1..n
    if (B == NULL) return -1;                       // 分配失败（考试可不写）
    for (i = 0; i <= n; i++)
        B[i] = 0;                                   // B[1..n] 全部初始化为 0
    for (i = 0; i < n; i++)
        if (A[i] >= 1 && A[i] <= n)                 // 只标记 1..n 范围内的正整数
            B[A[i]] = 1;                            // 记录该值出现过
    for (i = 1; i <= n; i++)
        if (B[i] == 0) {                            // 第一个未出现的正整数
            free(B);
            return i;
        }
    free(B);
    return n + 1;                                   // 1..n 全部出现，答案为 n+1
}
```

**复杂度分析**：

- **时间**：第一趟扫描数组 n 次，第二趟检查标记数组最多 n 次，总 O(n)。相比排序法 O(n log n)，是时间最优解。
- **空间**：辅助数组 B 长度 n+1，O(n)。

**与常见解法的对比**：

| 解法 | 时间 | 空间 | 特点 |
| --- | --- | --- | --- |
| 辅助数组标记（本题） | O(n) | O(n) | 时间最优，思路直接 |
| 排序后扫描缺口 | O(n log n) | O(1)~O(log n) | 时间非最优 |
| 原地哈希（交换归位） | O(n) | O(1) | 若允许修改数组可进一步省空间 |
| 哈希集合 | O(n) | O(n) | 与本题等价，但题目暗示数组元素含负数时用 B 下标更直接 |

**原地归位变式**（若题目允许修改数组且要求 O(1) 空间）：把每个值在 `1..n` 的元素换到下标 `值-1` 的位置（循环交换），再扫描第一个 `A[i] != i+1` 的位置返回 `i+1`；全对齐则返回 `n+1`。时间仍 O(n)（每个元素最多被换一次到位），空间 O(1)。

## 根因分析

未作答，属首次接触「辅助数组标记 / 缺失正整数」题型。易错点集中在：

1. **想不到「答案 ≤ n+1」**：试图对所有元素排序或对整个值域开标记数组，复杂度失控。这一步是解题的关键——n 个元素的数组中，`1 ~ n` 必有缺口。
2. **忽略负数和 0**：直接 `B[A[i]] = 1` 会越界。必须先判断 `A[i] >= 1`，负数与 0 不参与标记。
3. **忽略大于 n 的正整数**：误以为它们也要标记。实际上答案不可能超过 n+1，大于 n 的值对结果无影响，标记它们反而浪费空间。
4. **标记数组长度写错**：应为 n+1（下标 0~n，其中下标 0 弃用）而不是 n；若用 `B[n]` 存最大值会越界。
5. **忘处理「全部出现」的边界**：`1 ~ n` 全部出现时返回 `n + 1`，不能返回 -1 或 0（题目要求输出的是正整数）。
6. **混淆「最小正整数」与「最小整数」**：负数再小也不是候选，答案从 1 开始找。
7. **malloc 后忘记 free**：C 语言实现中动态分配的内存必须释放，虽然不影响算法正确性，但考场会扣代码规范性分。

## 完整知识点梳理

**辅助数组标记（桶标记）思想**：用「值 → 下标」的映射把「某个值是否出现」变成 O(1) 可查的状态。适用于值域有限（如本题 `1..n`）的查找/去重/计数问题。

| 题型 | 标记数组下标含义 | 复杂度 |
| --- | --- | --- |
| 查找未出现的最小正整数（本题） | `B[i]=1` 表示正整数 i 出现过 | O(n) / O(n) |
| 删除链表中绝对值相等的结点（2015-41） | `B[i]=1` 表示绝对值 i 出现过 | O(n) / O(n) |
| 查找数组中只出现一次的元素 | `B[i]` 计数 | O(n) / O(n) |
| 判断数组是否存在重复元素 | `B[i]=1` 表示出现过 | O(n) / O(n) |

**判定法则（考场速记）**：

1. 看到「长度 n 的数组 + 找缺失/未出现 + 值域与 n 相关」→ 优先考虑辅助数组标记，答案范围往往是 `1 ~ n+1`。
2. **范围过滤**是核心：只标记对答案有贡献的值（本题 `1..n`），其余直接跳过。
3. **复杂度权衡**：辅助数组用 O(n) 空间换 O(n) 时间；若题目限制 O(1) 空间，改用原地归位（循环交换）。
4. **值域含负数/0** 时，辅助数组下标从 1 开始最安全，负数和 0 直接跳过。
5. 若值域极大（如 32 位整数），辅助数组不可行，改用哈希集合或排序。

**与相关真题的关联**：

- 2015-41「删除链表中绝对值相等的多余结点」：同样是辅助数组标记，值域是 `1..m`（题目给出绝对值上限）。
- 2018-41（本题）：辅助数组标记，值域 `1..n`。
- 两者都是「值域有限 → 桶标记 → 一趟扫描」的同型题。

**记忆口诀**：

> **「n 个数找缺口，答案不过 n 加一；标记只记一到 n，负零大数全跳过。」**

## 复刷清单

### 举一反三 5 题

1. 【单选】长度为 n 的整数数组中「未出现的最小正整数」的取值范围是（ ）。
   A. 1 ~ n
   B. 1 ~ n+1
   C. 1 ~ 2n
   D. 任意正整数
   **答案：B**。若 1~n 全部出现答案为 n+1；否则 1~n 中必有缺口。n 个元素最多覆盖 n 个不同的值。

2. 【单选】对数组 `{-5, 3, 2, 3}`，辅助数组标记法的输出是（ ）。
   A. -5
   B. 0
   C. 1
   D. 4
   **答案：C**。-5 不在 1..n 内被跳过；3、2 出现被标记；1 未出现，故输出 1。

3. 【单选】辅助数组标记法中，对数组元素 `A[i]` 的处理规则是（ ）。
   A. 直接 `B[A[i]] = 1`
   B. 仅当 `1 ≤ A[i] ≤ n` 时 `B[A[i]] = 1`
   C. 仅当 `A[i] > 0` 时 `B[A[i]] = 1`
   D. 仅当 `A[i] < n` 时 `B[A[i]] = 1`
   **答案：B**。负数和 0 会越界；大于 n 的数对答案无贡献，标记它浪费空间且可能越界。

4. 【单选】若题目限制空间 O(1) 且允许修改数组，求未出现的最小正整数应改用（ ）。
   A. 排序后扫描
   B. 原地归位（循环交换使 A[i] = i+1）
   C. 哈希集合
   D. 摩尔投票
   **答案：B**。原地归位把值 v 换到下标 v-1，再扫第一个不对齐的位置，O(n)/O(1)。

5. 【单选】对数组 `{1, 2, 3}`（n=3），辅助数组标记法的输出是（ ）。
   A. 0
   B. 1
   C. 3
   D. 4
   **答案：D**。1~3 全部出现，返回 n+1 = 4。

### 历年真题风格练习

1. 【2018-41 原题】给定含 n 个整数的数组，设计尽可能高效的算法找出未出现的最小正整数，输出该值；要求给出思想、C 代码与复杂度。
   **答案**：辅助数组标记法，O(n)/O(n)，见上文参考算法。

2. 【真题改编】若数组元素都是正整数且值域为 1..m（m 已知且 m >> n），如何求未出现的最小正整数？复杂度是多少？
   **答案**：仍用长度 n+1 的标记数组（值域超过 n 的元素跳过），逻辑与本题一致，O(n)/O(n)。值域 m 很大但答案仍 ≤ n+1，与 m 无关。

3. 【真题改编】设计 O(n) 时间、O(1) 空间的算法求未出现的最小正整数（允许修改数组）。
   **答案**：原地归位：对每个 A[i]，当 1 ≤ A[i] ≤ n 且 A[A[i]-1] != A[i] 时交换 A[i] 与 A[A[i]-1]；结束后扫第一个 A[i] != i+1 的位置返回 i+1；全对齐返回 n+1。每个元素最多被交换一次到位，总交换 O(n)。
