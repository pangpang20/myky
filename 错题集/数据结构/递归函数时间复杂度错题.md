## 题目

### T1：单分支递归（答错）

设 n 为正整数。下列递归函数的时间复杂度是（ ）。

```c
int f(int n) {
    if (n <= 1) return 1;
    return f(n / 2) + 1;
}
```

A. O(log₂ n)　B. O(n)　C. O(n log₂ n)　D. O(n²)

**我的答案**：B（作答错误）。**正确答案**：A。

### T2：双分支 + 线性层（对照，答对）

```c
void f(int n) {
    if (n <= 1) return;
    f(n / 2);
    f(n / 2);
    for (i = 1; i <= n; i++) count++;
}
```

**正确答案**：C O(n log₂ n)（归并排序型，主定理 T(n)=2T(n/2)+O(n)）。

### T3：双分支递归、无内层循环（答错）

```c
void f(int n) {
    if (n <= 1) return;
    f(n - 1);
    f(n - 1);
}
```

**我的答案**：B O(n log₂ n)（作答错误）。**正确答案**：D O(2ⁿ)。

### T4：斐波那契递归（答错）

```c
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
```

**我的答案**：A O(n)（作答错误）。**正确答案**：D O(2ⁿ)。

### T5：双分支 + 无层（答错）

```c
void f(int n) {
    if (n <= 1) return;
    f(n / 3);
    f(n / 3);
}
```

**我的答案**：A O(log₂ n)（作答错误）。**正确答案**：B O(n^(log₂ 3)) ≈ O(n^1.585)。

## 根因分析

四道错题共用一个根因：**把「递归调用次数」当成了「每层只有 1 次调用」**。

1. **T1（f(n/2)+1）**：我直觉选了 O(n)，实际每次只有一个调用，递归深度 log₂ n → **O(log n)**。
2. **T3（f(n-1)×2）**：我把「两个 f(n-1)」当成「两倍 n = O(n log n)」，实际调用树是 2ⁿ 个叶子 → **O(2ⁿ)**。
3. **T4（fib）**：我以为是「两个递归相加≈O(n)」，实际 fib(n-1)+fib(n-2) 每层分裂两个分支，调用树≈2ⁿ → **O(2ⁿ)**（更精确 ≈ O(1.618ⁿ)，统考按 O(2ⁿ) 计）。
4. **T5（f(n/3)×2）**：我看到「两个 f(n/3)」直接选了 O(log n)，忽略了**分支因子**：T(n)=2T(n/3)，主定理 a=2,b=3,f(n)=1 → n^(log₃ 2) ≈ n^0.63 → 总量 **n^(log₂? 3)…** 更正：**T(n) = O(n^(log₃ 2))**，选项 B 写作 O(n^(log₂ 3)) 是笔误，量级介于 O(log n) 与 O(n) 之间。

**核心混淆**：递归复杂度 = 调用树规模，不是「分支数 × 深度」。分支因子 2 与缩减速度共同决定叶子数。

## 完整知识点梳理

递归复杂度的通用方法：**画调用树，数叶子**。总调用次数 = 树节点总数。

| 递推式 | 分支因子 a | 缩减因子 b | 额外工作 f(n) | 复杂度 |
| --- | --- | --- | --- | --- |
| T(n)=T(n/2)+O(1) | 1 | 2 | O(1) | **O(log n)** |
| T(n)=2T(n/2)+O(n) | 2 | 2 | O(n) | **O(n log n)**（归并） |
| T(n)=2T(n-1)+O(1) | 2 | n-1 | O(1) | **O(2ⁿ)** |
| T(n)=T(n-1)+T(n-2)+O(1) | 2 | n-1 | O(1) | **O(2ⁿ)**（≈1.618ⁿ） |
| T(n)=2T(n/3)+O(1) | 2 | 3 | O(1) | **O(n^(log₃ 2)) ≈ O(n^0.63)** |

**主定理（Master Theorem）**：T(n)=aT(n/b)+O(n^d)，比较 a 与 b^d：
- a < b^d → O(n^d)
- a = b^d → O(n^d log n)
- a > b^d → **O(n^(log_b a))**

**关键判定法则**：
1. 单分支（a=1）：复杂度 = 深度 × 每层工作。
2. 多分支（a≥2）+ 每层 O(n) 工作：常见 O(n log n)。
3. 多分支 + 每层 O(1)：叶子数主导，接近 O(a^depth)。
4. 斐波那契型：分支递增 → 指数级 O(2ⁿ)。
5. 「两个递归」不等于「两倍时间」，要同时看缩减速度。

**记忆口诀**：

> **「画树数叶，主定理定级」**——先看分支数 a 与缩减因子 b，再套 a vs b^d。

## 复刷清单

### 举一反三 5 题

1. 【单选】T(n) = T(n/2) + O(1) 的复杂度是（ ）。
   A. O(1)　B. O(log n)　C. O(n)　D. O(n log n)
   **答案：B**。单分支、深度 log₂ n、每层 O(1)。

2. 【单选】T(n) = 2T(n/2) + O(n) 的复杂度是（ ）。
   A. O(log n)　B. O(n)　C. O(n log n)　D. O(n²)
   **答案：C**。a=2,b=2,d=1 → a=b^d → n log n（归并排序）。

3. 【单选】T(n) = 2T(n-1) + O(1) 的复杂度是（ ）。
   A. O(n)　B. O(n log n)　C. O(2ⁿ)　D. O(n²)
   **答案：C**。满二叉递归树，深度 n，节点 2ⁿ-1。

4. 【单选】T(n) = T(n-1) + O(n) 的复杂度是（ ）。
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(2ⁿ)
   **答案：C**。单分支、每层 O(n)，Σn = O(n²)（快速排序最坏）。

5. 【单选】T(n) = 2T(n/3) + O(1) 的复杂度是（ ）。
   A. O(log n)　B. O(n^0.63)　C. O(n)　D. O(n log n)
   **答案：B**。a=2,b=3 → n^(log₃ 2) ≈ n^0.63，介于 log 与线性之间。

### 历年真题风格练习

1. 【统考风格】下列递归函数的时间复杂度是（ ）。
   ```c
   int g(int n) {
       if (n == 1) return 1;
       return 2 * g(n / 2);
   ```
   A. O(1)　B. O(log n)　C. O(n)　D. O(n log n)
   **答案：B**。单分支、深度 log₂ n、每层 O(1)。

2. 【统考风格】T(n)=4T(n/2)+O(n) 的复杂度是（ ）。
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(n³)
   **答案：C**。a=4,b=2 → n^(log₂ 4) = n²，a>b^d → O(n²)。

3. 【统考风格】下列关于递归复杂度的说法，正确的是（ ）。
   A. 递归函数中每层都调用自己两次，则复杂度一定为 O(n log n)
   B. 单分支递归的复杂度一定为 O(n)
   C. 递归复杂度由「分支数 × 缩减速度」共同决定，需结合主定理或调用树计算
   D. 斐波那契递归 fib(n)=fib(n-1)+fib(n-2) 的复杂度为 O(n)
   **答案：C**。分支数与缩减速度共同决定，如 T(n)=2T(n/2)+O(1) 是 O(n)，而 T(n)=2T(n-1)+O(1) 是 O(2ⁿ)。
