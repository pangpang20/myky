# 倍增外层·内层依赖求和的复杂度错题

## 错题信息

- 科目：数据结构
- 章节：第 1 章 基本概念与时空复杂度
- 收录日期：2026-11-14
- 我的答案：C（O(n log₂ n)）
- 正确答案：B（O(n)）
- 状态：待复刷（艾宾浩斯第 1 轮）

## 题目

设 n 为正整数。下列程序段的时间复杂度是（ ）。

```c
for (i = 1; i <= n; i *= 2)
    for (j = 1; j <= i; j++)
        count++;
```

A. O(log₂ n)　B. O(n)　C. O(n log₂ n)　D. O(n²)

## 根因分析

我只看到「外层 i *= 2 是 log n 次」，就想当然地把内层当成固定 n 次，直接相乘得到 O(n log n)。**实际上内层的上界 i 是跟着外层变化的**——i 依次取 1, 2, 4, 8, …, n，内层循环次数就是 1, 2, 4, 8, …, n。

总次数 = 1 + 2 + 4 + … + 2^k（其中 2^k ≤ n < 2^(k+1)）= 2^(k+1) − 1 ≈ 2n，量级 **O(n)**。

核心误判点：**内层上界依赖外层变量时，必须逐层求和，不能把外层次数乘以内层某个"典型值"**。如果内层是固定的 `j < n`，才是 O(n log n)；这里内层是 `j <= i`，属于"依赖型"，结果降一阶。

## 完整知识点梳理

### 判定流程（三步）

1. **看内层是否依赖外层变量**
   - 不依赖（如 `j < n`）：直接相乘 → 外层次数 × 内层次数
   - 依赖（如 `j <= i`、`j < i*i`）：**必须求和**，不能相乘
2. **写出求和式**，例如 Σ(i 的表达式)
3. **用等比/等差/平方和公式化简**，取最高阶

### 常见组合对照表

| 外层 | 内层 | 总次数 | 复杂度 |
| --- | --- | --- | --- |
| `i=1; i<n; i++`（n 次） | `j<n`（n 次，独立） | n² | O(n²) |
| `i=1; i<n; i*=2`（log n 次） | `j<n`（n 次，独立） | n log n | **O(n log n)** |
| `i=1; i<=n; i*=2`（log n 次） | `j<=i`（依赖） | 1+2+4+…+n ≈ 2n | **O(n)** |
| `i=1; i<n; i++`（n 次） | `j<i`（依赖） | 0+1+…+(n−1) ≈ n²/2 | O(n²) |
| `i=1; i<n; i++`（n 次） | `j<i*i`（依赖） | Σi² ≈ n³/3 | O(n³) |

### 关键公式

- 等比数列：1 + 2 + 4 + … + 2^k = 2^(k+1) − 1
- 等差求和：1 + 2 + … + n = n(n+1)/2
- 平方和：1² + 2² + … + n² ≈ n³/3

### 一句话记忆

> **内层跟着外层走 → 求和降阶；内层不动 → 直接相乘。**
> `i *= 2` 配 `j <= i`，求和得 2n，是 O(n) 不是 O(n log n)。

## 复刷清单

### 举一反三 5 题

1. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i *= 2)
       for (j = 1; j <= i; j++)
           count++;
   ```
   A. O(log₂ n)　B. O(n)　C. O(n log₂ n)　D. O(n²)
   **答案：B**。外层 i 取 1,2,4,…,n，内层次数随之是 1,2,4,…,n，求和 ≈ 2n。

2. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i *= 2)
       for (j = 1; j <= n; j++)
           count++;
   ```
   A. O(log₂ n)　B. O(n)　C. O(n log₂ n)　D. O(n²)
   **答案：C**。内层固定 n 次、与外层无关，直接相乘 log n × n。

3. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i *= 2)
       for (j = 1; j <= i * i; j++)
           count++;
   ```
   A. O(n)　B. O(n²)　C. O(n log n)　D. O(n³)
   **答案：B**。内层次数为 i²，Σ(2^k)² = 1+4+16+…≈ (4/3)n²，量级 O(n²)。

4. 【单选】执行 `for (i = 1; i <= n; i *= 2) for (j = 1; j <= i; j++) count++;` 时，count++ 的**精确**执行次数最接近（ ）。
   A. n　B. 2n − 1　C. n log₂ n　D. n²
   **答案：B**。等比求和 1+2+4+…+2^k = 2^(k+1) − 1，当 2^k ≤ n 时约为 2n − 1。

5. 【单选】下列关于「外层倍增 + 内层依赖」的判断，正确的是（ ）。
   A. 只要外层是 i *= 2，复杂度一定是 O(n log n)
   B. 内层上界依赖外层变量时，必须逐层求和，结果可能比「相乘」低一阶
   C. 内层依赖外层时，复杂度一定比内层独立时高
   D. 外层倍增说明总次数一定是对数级
   **答案：B**。判定核心是「内层是否依赖」，依赖则求和；本题求和后是 O(n)，比相乘的 O(n log n) 低一阶。

### 历年真题风格练习

1. 【统考风格】设 n 为正整数，下列程序段的时间复杂度是（ ）。
   ```c
   int i = 1, s = 0;
   while (i <= n) {
       for (int j = 1; j <= i; j++) s++;
       i *= 2;
   }
   ```
   A. O(log₂ n)　B. O(n)　C. O(n log₂ n)　D. O(n²)
   **答案：B**。与 while 写法等价，内层次数为 i，求和 1+2+4+…≈ 2n。

2. 【统考风格】若把上题内层条件改为 `j <= n`（与 i 无关），时间复杂度变为（ ）。
   A. O(log₂ n)　B. O(n)　C. O(n log₂ n)　D. O(n²)
   **答案：C**。内层独立于外层，log n × n。

3. 【统考风格】下列两段程序中，时间复杂度相同的是（ ）。
   甲：`for(i=1;i<=n;i*=2) for(j=1;j<=i;j++) f();`
   乙：`for(i=1;i<=n;i++) for(j=1;j<=n;j+=2) f();`
   A. 都是 O(n log n)　B. 甲 O(n)、乙 O(n²)　C. 都是 O(n)　D. 甲 O(log n)、乙 O(n)
   **答案：B**。甲求和 ≈ 2n；乙为 n × (n/2) ≈ n²/2，量级 O(n²)。
