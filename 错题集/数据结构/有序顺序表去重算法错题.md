## 题目

```
从有序顺序表中删除所有重复值的元素，使表中所有元素的值均不相同。
```

（算法设计题，无选项）

## 参考解答

**核心思路**：有序表中重复元素一定相邻。用 `k` 记录「去重结果」的下一个空位，`i` 扫描全表，遇到与最后一个已保留值不同的元素就前移到 `k`。一次遍历完成原地去重。

```c
int DeleteDuplicates(SqList *L) {
    if (L->length <= 1) return L->length;   // 空表或单元素无需处理
    int k = 1;                              // k-1 = 已保留的最后一个元素下标
    for (int i = 1; i < L->length; i++) {
        if (L->data[i] != L->data[k-1]) {
            L->data[k++] = L->data[i];
        }
    }
    L->length = k;
    return k;
}
```

**正确性**：`data[0..k-1]` 恒为严格递增序列；每次保留的条件是「与已保留末值不同」，正好跳过所有重复。

**复杂度**：时间 O(n)（i 只走一遍），空间 O(1)（原地覆盖，不用辅助数组）。

## 根因分析

用户未作答，属首次接触此类算法题。常见错误做法与陷阱：
1. **逐个删除重复**：发现 data[i]==data[i+1] 就整体左移 → 每次删除 O(n)，总 O(n²)，考研要求 O(n)。
2. **借辅助数组**：先筛出唯一值再拷回，思路可行但空间 O(n)，违反原地 O(1) 约定。
3. **边界遗漏**：空表或单元素直接进入循环会越界；k 初始为 0 会导致首个元素丢失。
4. **误以为无序表也能这么解**：相邻比较只对有序表成立，无序表需哈希或双循环。

## 完整知识点梳理

**顺序表常见 O(n) 原地操作模板**（双指针/读写指针）：

| 题型 | 指针含义 | 保留条件 |
| --- | --- | --- |
| 有序表去重（本题） | k=去重结果长度 | data[i] != data[k-1] |
| 删除所有值为 x 的元素 | k=保留个数 | data[i] != x |
| 奇偶分区 | k=偶数区末尾 | data[i] 为奇数时前移 |
| 有序表合并 | i/j 双读指针，k 写指针 | 每次取较小者 |

**关键判定法则**：
1. 「原地 + 高效」→ 优先双读写指针，禁止辅助数组。
2. 有序性是「只比较相邻/末值」的前提。
3. 覆盖式写入（data[k++]=data[i]）不会破坏未处理数据，因为 k ≤ i 恒成立。
4. 循环结束后记得更新 L->length，考场上常漏。

**记忆口诀**：

> **「读写双针走一遍，末值不同才保留」**——k 是保留区末尾+1，i 只前进不回头。

## 复刷清单

### 举一反三 5 题

1. 【单选】对长度为 n 的有序顺序表去重，最优算法的时间复杂度是（ ）。
   A. O(1)　B. O(log n)　C. O(n)　D. O(n²)
   **答案：C**。双指针一次扫描。

2. 【单选】若顺序表**无序**，删除所有重复元素的最优时间复杂度是（ ）。
   A. O(n)　B. O(n log n)　C. O(n²)（不排序）　D. O(n²)
   **答案：B**。先排序 O(n log n) 再 O(n) 去重；不排序只能 O(n²)。

3. 【单选】双指针去重中，k 与 i 的关系始终满足（ ）。
   A. k = i　B. k ≤ i　C. k ≥ i　D. 无固定关系
   **答案：B**。k 只在有新值时 +1，永远不超前于 i。

4. 【单选】删除顺序表中所有值为 x 的元素（O(n)、O(1)）的保留条件是（ ）。
   A. data[i] != data[k-1]　B. data[i] != x　C. data[i] == x　D. data[i] > x
   **答案：B**。这是「按值过滤」模板，与去重的「按末值比较」区分。

5. 【单选】算法结束后若忘记更新 L->length，直接后果是（ ）。
   A. 表数据丢失　B. 表尾残留旧值但逻辑长度正确　C. 逻辑长度仍是旧值，读到重复/垃圾元素　D. 编译错误
   **答案：C**。length 是逻辑边界，必须收口。

### 历年真题风格练习

1. 【统考风格·2015 真题改编】从顺序表中删除其值在 s 与 t 之间（含 s、t，s<t）的所有元素，要求 O(n)、O(1)，写出算法。
   **答案**：k 记保留个数，条件 `data[i] < s || data[i] > t` 时保留；最后 L->length=k。一次扫描完成。

2. 【统考风格】设计算法将有序顺序表中**值相同的多余元素**删除，使各值只保留一个，要求不移动多余次数。
   **答案**：即本题双指针解法；核心是 data[i] 与 data[k-1] 比较，保证 O(n)。

3. 【统考风格】有两个递增有序顺序表 A、B，设计算法将 A 中不在 B 中出现的元素原地保留，要求 O(n)。
   **答案**：i 扫 A、j 扫 B，双归并比较；A[i]==B[j] 时跳过（重复），A[i]<B[j] 保留 A[i] 并 i++，A[i]>B[j] 则 j++；最后 length=保留数。
