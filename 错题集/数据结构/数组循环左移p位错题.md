## 题目

设将 `n(n>1)` 个整数存放到一维数组 R 中，设计一个在时间和空间两方面都尽可能高效的算法，将 R 中保存的序列循环左移 `p(0<p<n)` 个位置，即将 R 中的数据由 `<x0,x1,…,x(n-1)>` 变换为 `<xp,x(p+1),…,x(n-1),x0,x1,…,x(p-1)>`。要求：

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C / C++ / Java 描述，关键之处给出注释。
3. 说明算法的时间复杂度和空间复杂度。

## 参考解答

### (1) 基本设计思想

把数组看成两段：前 `p` 个元素 `Xa = <x0,…,x(p-1)>`，后 `n-p` 个元素 `Xb = <xp,…,x(n-1)>`。

三次逆置即可完成循环左移：

1. 先逆置前 `p` 个元素 → `<x(p-1),…,x0, xp,…>`
2. 再逆置后 `n-p` 个元素 → `<x(p-1),…,x0, x(n-1),…,xp>`
3. 最后整体逆置 → `<xp,…,x(n-1), x0,…,x(p-1)>`

等价公式：**`A = Xa·Xb`，先分别逆置 `A⁻¹ = Xa⁻¹·Xb⁻¹`，再整体逆置得 `(Xa⁻¹·Xb⁻¹)⁻¹ = Xb·Xa`**，即左移结果。

### (2) C 语言描述

```c
void Reverse(int R[], int from, int to) {
    for (int i = 0; i < (to - from + 1) / 2; i++) {
        int tmp  = R[from + i];      // 交换 R[from+i] 与 R[to-i]
        R[from+i] = R[to-i];
        R[to-i]  = tmp;
    }
}

void LeftShift(int R[], int n, int p) {
    if (p <= 0 || p >= n) return;    // p 合法性检查
    Reverse(R, 0, p - 1);            // 逆置前 p 个元素
    Reverse(R, p, n - 1);            // 逆置后 n-p 个元素
    Reverse(R, 0, n - 1);            // 整体逆置
}
```

**关键注释**：
- `Reverse(R, from, to)`：双端向中间交换，一趟逆置。
- `LeftShift` 三次调用分别对应设计思想的三个步骤，总交换次数 `⌊p/2⌋ + ⌊(n-p)/2⌋ + ⌊n/2⌋ = n`，每对元素只交换一次。

### (3) 复杂度

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| **三次逆置（本题）** | O(n) | O(1) | 逆置总交换 n 次 |
| 辅助数组 | O(n) | O(n) | 违反"空间尽可能高效" |
| 逐次左移 1 位 × p 次 | O(pn) | O(1) | 时间不优 |
| 辗转相除（循环移位链） | O(n) | O(1) | 正确但实现复杂，易错 |

## 根因分析

用户未作答，属首次接触此题型。常见错误：

1. **用辅助数组**：先拷贝 `xp..x(n-1)` 再拼接，时间 O(n) 但空间 O(n)，违反题目"空间尽可能高效"的约束。
2. **逐位左移**：每次整体左移 1 位、重复 p 次，时间 O(pn)，效率低。
3. **逆置顺序错**：三步顺序颠倒或漏掉整体逆置，结果仍是逆序或半逆序。
4. **p 越界**：p=0 或 p≥n 时循环数组行为与预期不符，未做合法性检查。

## 完整知识点梳理

**顺序表循环移位的 O(n)/O(1) 套路**：

| 方法 | 核心操作 | 复杂度 |
| --- | --- | --- |
| **三次逆置** | Reverse(0,p-1) + Reverse(p,n-1) + Reverse(0,n-1) | O(n) / O(1) |
| 辅助数组 | 拷贝 → 拼接 | O(n) / O(n) |
| 逐位移动 | p 次 × 每次整体移 1 位 | O(pn) / O(1) |
| 循环移位链（辗转相除） | 按 gcd(n,p) 分环逐位换 | O(n) / O(1) |

**关键判定法则**：

1. 「时间、空间均尽可能高效」→ O(n)/O(1)，排除辅助数组。
2. 逆置是**原地的**，总交换次数 `⌊p/2⌋+⌊(n-p)/2⌋+⌊n/2⌋ = n`。
3. 右移 p 位可化为左移 `n-p` 位，或用相同三步（顺序：整体、前段、后段）。
4. 逆置法不仅适用于循环移位，还适用于**字符数组的循环移动**（如"ABCD → CDAB"）。

**原理图例**（Mermaid 示意，`n=7, p=3`）：

```mermaid
flowchart LR
    A["原数组<br/>1 2 3 4 5 6 7"] --> B["逆置前 p=3 位<br/>3 2 1 4 5 6 7"]
    B --> C["逆置后 4 位<br/>3 2 1 7 6 5 4"]
    C --> D["整体逆置<br/>4 5 6 7 1 2 3"]
    D --> E["= 循环左移 3 位结果"]
```

**记忆口诀**：

> **「前逆后逆再全逆，三步出结果」**——段逆置两次 + 整体逆置一次。
