## 第 1 题：算法特性

**题干**：一个算法应该具有（ ）等重要特性。  
**我的答案**：C（确定性、有穷性和可靠性）  
**正确答案**：B（可行性、确定性和有穷性）

### 根因分析

我选了「可靠性」，但**可靠性不是算法的必备特性**，它更多是工程/系统层面的质量属性。「可读性」「可维护性」同样不是算法的必备特性，它们是**好算法的设计目标**，不是「算法之所以成为算法」的判定条件。

### 完整知识点梳理：算法五大特性（缺一不可）

| 特性 | 含义 | 常见误选项 |
| --- | --- | --- |
| **有穷性** | 算法必须在有限步骤内终止 | 易与「可靠性」混淆 |
| **确定性** | 每条指令含义明确，无二义性 | 易与「可读性」混淆 |
| **可行性** | 每个操作都可以通过基本运算有限次实现 | 易被忽略 |
| **输入** | 有零个或多个输入 | — |
| **输出** | 至少一个输出 | — |

**记忆口诀**：**有穷、确定、可行 + 输入输出**。
「可读性、可维护性、可靠性、健壮性、高效性」都是**好算法的评价标准**，不是算法的判定条件。

## 第 2 题：大 O 定义

**题干**：T(n) = O(n²)，则必然成立的是（ ）。  
**我的答案**：D（T(n) 与 n² 成正比）  
**正确答案**：C（存在常数 c > 0 和 n₀，使所有 n ≥ n₀ 都满足 T(n) ≤ c·n²）

### 根因分析

「成正比」意味着 T(n) = k·n²，这是一个**精确比例关系**。但大 O 只是一个**上界**：T(n) 可能是 n²、n log n、n、常数——只要最终增长不超过 c·n² 即可。我把「不超过 n² 阶」理解成了「恰好 n² 阶」。

### 完整知识点梳理：大 O 严格定义

若存在正常数 c 和 n₀，使得所有 n ≥ n₀ 都有 **T(n) ≤ c·f(n)**，则 T(n) = O(f(n))。

关键点：
1. 大 O 是**渐进上界**，不是精确表达式。
2. T(n) = O(n²) 也意味着 T(n) = O(n³)、O(2ⁿ)……大 O 是「不超过」关系。
3. 「成正比」对应的是 Θ（渐进紧确界），不是 O。
4. 大 Ω 是下界（T(n) ≥ c·f(n)）。

**对照表**：

| 记号 | 含义 | 直觉 |
| --- | --- | --- |
| O(f) | 上界 | 增长不超过 f 阶 |
| Ω(f) | 下界 | 增长不低于 f 阶 |
| Θ(f) | 紧确界 | 增长恰好是 f 阶 |

## 第 3 题：i = i*i 循环

**题干**：
```c
i = 2;
while (i < n)
    i = i * i;
```
**我的答案**：C（O(n^(1/2))）  
**正确答案**：D（O(log log n)）

### 根因分析

i 的增长序列是 2 → 4 → 16 → 256 → …，即每次平方。我按「平方根增长」误判，实际是**平方增长**，迭代次数是「对数套对数」。

### 完整知识点梳理：迭代次数推导

设第 k 次迭代后 i = a_k。a₀ = 2，a_{k+1} = a_k²。

迭代次数 k 满足 a_k ≥ n，即 2^(2^k) ≥ n，两边取对数：
2^k ≥ log₂ n，再取一次对数：**k ≥ log₂ log₂ n**。

所以时间复杂度是 **O(log log n)**。

**常见循环模式速查**：

| 循环形式 | i 变化 | 复杂度 |
| --- | --- | --- |
| i = i + 1 | 线性 | O(n) |
| i = i * 2 | 指数 | O(log n) |
| i = i * i | 平方级指数 | O(log log n) |
| i = i + c（c>0） | 线性 | O(n) |
| i = sqrt(i) | 缩小 | O(log log n) |

## 第 4 题：嵌套循环计数

**题干**：
```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= 2 * i; j++)
        m++;
```
**我的答案**：D（n²）  
**正确答案**：A（n(n+1)）

### 根因分析

内层循环次数不是 i，是 **2i**。总执行次数 = Σ(i=1→n) 2i = 2·n(n+1)/2 = **n(n+1)**。我看成了普通的双重循环，没做求和。

### 知识点梳理

1. 内层次数依赖外层变量时，**必须写求和式**，不能凭形式判断。
2. Σ 2i = n(n+1)，是 O(n²) 但**不是 n²**。
3. 常见求和公式：
   - Σ i = n(n+1)/2
   - Σ 2i = n(n+1)
   - Σ log i ≈ log(n!)

**陷阱提示**：当答案同时给出 n² 和精确和时，通常精确和才是正确答案——n² 只是它的量级，不是执行次数。

## 第 5 题：链表合并复杂度

**题干**：两个长度分别为 m、n 的升序链表合并为降序链表，最坏情况时间复杂度是（ ）。  
**我的答案**：B（O(m×n)）  
**正确答案**：D（O(max(m,n))）

### 根因分析

我把「合并两个有序链表」误当成「两两比较」的 O(m×n) 过程。实际合并只需要**一次线性扫描**，每个节点最多访问一次，时间复杂度是 O(m+n)，而题目要求「最坏情况」，通常写作 O(max(m,n))——因为两链表长度不同时，扫描到较长链表末尾即结束。

### 知识点梳理

1. **合并有序链表**：双指针逐个比较，每个节点只处理一次，O(m+n) ≈ O(max(m,n))。
2. **O(m+n) 与 O(max(m,n)) 的关系**：当 m、n 都是正整数时，max(m,n) ≤ m+n ≤ 2·max(m,n)，二者同阶。
3. **O(m×n) 出现的场景**：嵌套遍历（如判断两个集合是否有公共元素且无辅助结构）。
4. **逆序输出**：头插法建新链表，不增加复杂度量级。

## 第 6、7、8 题：外层倍增/平方增长 + 内层线性求和

**第 6 题题干**：
```c
int sum = 0;
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++)
        sum++;
```
**我的答案**：D（O(n²)）　**正确答案**：B（O(n)）

**第 7、8 题题干**：
```c
int count = 0;
for (int i = 0; i * i < n; i++)
    for (int j = 0; j < i; j++)
        count++;
```
**我的答案**：C（O(N log₂ N)）　**正确答案**：B（O(N)）

### 根因分析

两层循环的复杂度**不等于**外层次数 × 内层次数的量级相乘——必须对内层次数求和。

### 完整知识点梳理：两层循环求和通法

**通式**：T(n) = Σ(i 变化) (内层次数)。

**第 6 题推导**：
外层 i = 1, 2, 4, 8, …, 2^k（其中 2^k < n），共 log₂n 次。
内层次数 = i 的取值 = 1 + 2 + 4 + … + 2^(log₂n−1) = 2^(log₂n) − 1 ≈ **n**。
所以 T(n) = O(n)，不是 O(n log n)，更不是 O(n²)。

**第 7、8 题推导**：
外层条件 i² < n，即 i < √n，共 √n 次。
内层次数 = i 的取值 = 0 + 1 + 2 + … + (√n − 1) ≈ **n/2**。
所以 T(n) = O(n)，不是 O(√n · √n) 形式上的「n log n」或「n²」。

**核心心法**：
1. **看到双层循环不要直接相乘**，先写求和式 Σ。
2. 内层次数依赖外层 i 时，代入 i 的具体取值序列再求和。
3. 常见结果：
   - 外层倍增 + 内层 i 次 → O(n)
   - 外层平方增长 + 内层 i 次 → O(n)
   - 外层 n 次 + 内层 i 次 → O(n²)
   - 外层 n 次 + 内层 log i 次 → O(n log n)

## 综合易错点汇总

| 陷阱 | 正确做法 |
| --- | --- |
| 把「好算法的评价标准」当「算法必备特性」 | 五大特性：有穷、确定、可行 + 输入输出 |
| 把大 O 当精确比例 | 大 O 是上界，「恰好」对应 Θ |
| 平方增长的循环误判为开方 | 逐次写出 i 的取值序列 |
| 嵌套循环直接量级相乘 | 写求和式 Σ，代入内层次数 |
| 有序链表合并误判为 O(mn) | 双指针线性扫描 O(max(m,n)) |
| 只看循环形式不做求和 | 外层序列 + 内层次数 → 求和 |

### 举一反三 5 题

1. 【单选】下列**不属于**算法必备特性的是（ ）。【注意否定词】
   A. 有穷性　B. 确定性　C. 高效性　D. 可行性
   **答案：C**。高效性是评价标准，不是判定条件。

2. 【单选】T(n) = O(n log n) 的严格含义是（ ）。
   A. T(n) 恰好等于 n log n　B. T(n) 与 n log n 成正比　C. 存在 c>0 和 n₀ 使 n≥n₀ 时 T(n) ≤ c·n log n　D. T(n) 的下界是 n log n
   **答案：C**。大 O 是上界，「恰好」是 Θ，「下界」是 Ω。

3. 【单选】下列循环的时间复杂度是（ ）。

```c
i = 1;
while (i < n)
    i = i * 3;
```

   A. O(n)　B. O(log₃ n)　C. O(n³)　D. O(log log n)
   **答案：B**。i 每次乘 3，迭代 log₃n 次。

4. 【单选】下列循环的时间复杂度是（ ）。

```c
i = n;
while (i > 1)
    i = sqrt(i);
```

   A. O(log log n)　B. O(log n)　C. O(sqrt n)　D. O(n)
   **答案：A**。开方操作迭代 log log n 次。

5. 【单选】下列循环的时间复杂度是（ ）。

```c
int sum = 0;
for (int i = 0; i < n; i++)
    for (int j = 0; j < sqrt(n); j++)
        sum++;
```

   A. O(n)　B. O(n log n)　C. O(n√n)　D. O(n²)
   **答案：C**。内层次数与 i 无关，直接 n × √n。

### 历年真题风格练习 3 题

1. 【统考风格】两个长度分别为 m、n 的有序**顺序表**合并，最坏情况比较次数是（ ）。
   A. O(m+n)　B. O(m×n)　C. O(max(m,n))　D. O(min(m,n))
   **答案：A**。顺序表合并每次比较确定一个元素，最多 m+n−1 次；链表合并的复杂度量级为 O(max(m,n))。

2. 【统考风格】下列循环中 sum++ 的执行次数是（ ）。

```c
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= i * i; j++)
        sum++;
```

   A. O(n²)　B. O(n³)　C. O(n⁴)　D. O(n log n)
   **答案：B**。Σ i² ≈ n³/3。

3. 【统考风格】T(n) = 3n² + 100n + 500，下列说法正确的是（ ）。
   A. T(n) = O(n²)　B. T(n) = O(n³)　C. T(n) = Θ(n²)　D. 以上都成立
   **答案：D**。大 O 是上界，n³ 也满足上界；该式恰好为 Θ(n²)；A、B、C 各自都成立。
