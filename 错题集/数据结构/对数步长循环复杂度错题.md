# 对数步长循环复杂度错题

## 错题信息

- 科目：数据结构
- 章节：第 1 章 基本概念与时空复杂度
- 收录日期：2026-11-14
- 我的答案：B（O(n)）
- 正确答案：C（O(n log₂ n)）
- 状态：待复刷（艾宾浩斯第 1 轮）

## 题目

设 n 为正整数。下列程序段的时间复杂度是（ ）。

```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= i; j *= 2)
        for (k = 1; k <= 10; k++)
            count++;
```

A. O(log n)　B. O(n)　C. O(n log₂ n)　D. O(n²)

## 根因分析

我把中层循环 `j *= 2` 误判为线性次数（选 B O(n)），忽略了**步长倍增意味着对数次数**：j 从 1 翻倍到超过 i，只需 ⌈log₂ i⌉ 次。内层固定 10 次是常数项，不影响量级。总次数 Σᵢ₌₁ⁿ log₂ i = log₂(1·2·…·n) = log₂(n!)，由 Stirling 公式 ≈ n·log₂ n，所以是 O(n log n)。同时把「log₂ n 只出现在单层对数循环」和「多层求和后的对数项」混为一谈。

## 完整知识点梳理

| 步长形式 | 内层次数 | 总复杂度 |
| --- | --- | --- |
| `j++`（线性） | i 次 | Σi = O(n²) |
| `j += i`（调和） | n/i 次 | Σn/i = n·H(n) = O(n log n) |
| `j *= 2`（对数） | log₂ i 次 | Σlog₂ i = log₂(n!) ≈ n·log₂ n = **O(n log n)** |
| `i /= 2`（外层减半） | — | log₂ n × 内层次数 |

**关键恒等式**：Σᵢ₌₁ⁿ log₂ i = log₂(n!) ≈ n·log₂ n（Stirling 公式：log₂(n!) ≈ n·log₂ n − 1.44n）。

**记忆口诀**：

> **「步长翻倍，次数对数」**——看到 `j *= 2` 就想 log₂ i，求和用 Stirling 转成 n·log₂ n。

## 复刷清单

### 举一反三 5 题

1. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= i; j *= 2) count++;
   ```
   A. O(log n)　B. O(n)　C. O(n log n)　D. O(n²)
   **答案：C**。去掉常数层不改变量级，Σ log₂ i ≈ n·log₂ n。

2. 【单选】Σᵢ₌₁ⁿ log₂ i 化简后等于（ ）。
   A. log₂(n!)　B. n·log₂ n（精确）　C. 2·log₂ n　D. n²
   **答案：A**。对数求和 = 对数之积 = log₂(n!)。

3. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = n; i >= 1; i /= 2)
       for (j = 1; j <= n; j++) count++;
   ```
   A. O(log n)　B. O(n log n)　C. O(n)　D. O(n²)
   **答案：B**。外层 log₂ n 次 × 内层 n 次。

4. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= i; j += i) count++;
   ```
   A. O(n log n)　B. O(n²)　C. O(n)　D. O(n log log n)
   **答案：A**。调和级数：Σ n/i = n·H(n) ≈ n·ln n。

5. 【单选】关于 `j += i` 与 `j *= 2` 两种内层步长，下列说法正确的是（ ）。
   A. 机理相同，都按比例缩放
   B. 前者每层 ≈ n/i 次（调和），后者每层 ≈ log₂ i 次（对数），量级都是 O(n log n)
   C. 后者的总次数是 O(n²)
   D. 前者的总次数是 O(n²)
   **答案：B**。机理不同但量级相同。

### 历年真题风格练习

1. 【统考风格】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i *= 2)
       for (j = 1; j <= n; j++) count++;
   ```
   A. O(n)　B. O(n log n)　C. O(log n · n)　D. B 与 C 相同
   **答案：D**。外层 log₂ n 次，内层 n 次 → n·log n，B 和 C 是同一表达。

2. 【统考风格】下列程序段中，总次数为 Θ(n log n) 的是（ ）。
   Ⅰ. `for(i=1;i<=n;i++) for(j=1;j<=i;j+=i)` 
   Ⅱ. `for(i=1;i<=n;i++) for(j=1;j<=i;j*=2)` 
   Ⅲ. `for(i=1;i<=n;i++) for(j=1;j<=n;j+=i)`
   A. 仅Ⅰ　B. 仅Ⅱ　C. Ⅰ和Ⅱ　D. Ⅰ、Ⅱ和Ⅲ
   **答案：D**。Ⅰ调和级数、Ⅱ对数求和、Ⅲ Σ n/i = n·H(n)，均为 O(n log n)。

3. 【统考风格】由 Stirling 公式，log₂(n!) 近似等于（ ）。
   A. n·log₂ n − 1.44n　B. n²/2　C. log₂ n × log₂ log₂ n　D. 2ⁿ
   **答案：A**。log₂(n!) ≈ n·log₂ n − (log₂ e)·n。
