## 题目

设 n 为正整数。下列程序段的时间复杂度是（ ）。

```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= i; j++)
        for (k = 1; k <= j; k++)
            count++;
```

A. O(n)　B. O(n²)　C. O(n log₂ n)　D. O(n³)

## 根因分析

我只看到了最外层的 n 次循环就选了 O(n)，完全忽略了**循环嵌套的逐层依赖**：内层循环的上界依赖外层变量，执行次数不是简单相乘，而是**逐层求和**。总执行次数为 Σ₁ⁿ Σ₁ⁱ Σ₁ʲ 1 = Σ₁ⁿ Σ₁ⁱ j = Σ₁ⁿ i(i+1)/2 ≈ n³/6，量级是 O(n³)。嵌套循环的复杂度要看「循环变量的依赖关系 + 求和的量级」，不能只看最外层。

## 完整知识点梳理

嵌套循环复杂度的通用方法：从内到外逐层求和，取最高阶项。

| 循环结构 | 执行次数 | 复杂度 |
| --- | --- | --- |
| 单层 `i<=n` | n | O(n) |
| 两层 `j<=i` | Σi = n²/2 | O(n²) |
| 三层 `k<=j`（本题） | Σ i(i+1)/2 ≈ n³/6 | **O(n³)** |
| 内层步长 `j+=i` | Σ n/i = n·H(n) | O(n log n) |

**关键判定法则**：
1. 各层循环边界相互独立 → 直接相乘，如三层独立 n 循环是 O(n³)。
2. 内层上界依赖外层变量（j <= i）→ 逐层求和，Σi = n²/2 → O(n²)。
3. 多层链式依赖（k <= j <= i <= n）→ 多重求和，量级 O(n³)。
4. 内层步长依赖外层变量（j += i）→ 调和级数，Σ n/i = n·H(n) → O(n log n)。

**记忆口诀**：

> **「嵌套逐层求和，依赖定形式」**——内层边界依赖外层时用求和算，最高阶项主导量级。

## 复刷清单

### 举一反三 5 题

1. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= i; j++) count++;
   ```
   A. O(n)　B. O(n²)　C. O(n log n)　D. O(n³)
   **答案：B**。Σi = n(n+1)/2 ≈ n²/2，量级 O(n²)。

2. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= n; j++) count++;
   ```
   A. O(n)　B. O(n²)　C. O(n log n)　D. O(n³)
   **答案：B**。两层边界独立，n × n = n²。

3. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= i; j++)
           for (k = 1; k <= n; k++) count++;
   ```
   A. O(n)　B. O(n²)　C. O(n³)　D. O(n⁴)
   **答案：C**。最内层边界独立：ΣΣ n = n·(n²/2) ≈ n³/2，量级 O(n³)。

4. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= i; j++)
           for (k = 1; k <= j; k++)
               for (l = 1; l <= k; l++) count++;
   ```
   A. O(n³)　B. O(n⁴)　C. O(n⁵)　D. O(n⁶)
   **答案：B**。四重链式求和的量级是 C(n+3,4) ≈ n⁴/24，量级 O(n⁴)。

5. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= i*i; j++) count++;
   ```
   A. O(n)　B. O(n²)　C. O(n³)　D. O(n⁴)
   **答案：C**。内层执行 i² 次，Σi² = n(n+1)(2n+1)/6 ≈ n³/3，量级 O(n³)。

### 历年真题风格练习

1. 【统考风格】设 n 为正整数，下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = i; j <= n; j++)
           for (k = 1; k <= j; k++) count++;
   ```
   A. O(n²)　B. O(n log n)　C. O(n³)　D. O(n⁴)
   **答案：C**。Σⱼ₌ᵢⁿ j ≈ (n²−i²)/2，再对 i 从 1 到 n 求和，最高阶项仍为 n³/6，量级 O(n³)。

2. 【统考风格】下列关于嵌套循环复杂度的说法，正确的是（ ）。
   A. 嵌套循环复杂度恒等于各层次数直接相乘
   B. 内层边界依赖外层时需逐层求和，量级由求和结果的最高阶项决定
   C. 只看最外层循环次数即可判断整体复杂度
   D. 嵌套循环的复杂度一定不超过 O(n²)
   **答案：B**。依赖关系决定求和形式，如本题 Σ i(i+1)/2 ≈ n³/6 → O(n³)。

3. 【统考风格】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= i; j++)
           for (k = 1; k <= i*j; k++) count++;
   ```
   A. O(n²)　B. O(n³)　C. O(n⁴)　D. O(n⁵)
   **答案：C**。最内层执行 i·j 次，ΣΣ ij = (Σi)² ≈ n⁴/4，量级 O(n⁴)。
