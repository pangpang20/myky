# 调和级数步长循环复杂度错题

## 错题信息

- 科目：数据结构
- 章节：第 1 章 基本概念与时空复杂度
- 收录日期：2026-11-14
- 我的答案：D（O(n²)）
- 正确答案：C（O(n log₂ n)）
- 状态：待复刷（艾宾浩斯第 1 轮）

## 题目

设 n 为正整数。下列程序段的时间复杂度是（ ）。

```c
for (i = 1; i <= n; i++)
    for (j = i; j <= n; j += i)
        count++;
```

A. O(log₂ n)　B. O(n)　C. O(n log₂ n)　D. O(n²)

## 根因分析

我把「内层步长 j += i」误判为「跳着走所以很快」，直接按 O(n²) 处理——这是**反向错误**：看到步长增大就以为总量变小，实际上内层从 i 开始、步长 i 前进，执行次数是 ⌊n/i⌋ 次。

总次数 = Σ(n/i)，i 从 1 到 n = n × (1 + 1/2 + 1/3 + … + 1/n) = **n·H(n)**，调和级数 H(n) ≈ ln n + 0.577，量级 **O(n log n)**。

核心误判点：
1. **步长增大 ≠ 总量变小**——每层次数变少，但层数多，求和要用调和级数。
2. **j += i 不是「跳过大多数」**——从 i 开始走，第一次就落在 i，然后 2i, 3i, …，共约 n/i 次。
3. 这是「**依赖型求和**」的另一个变体：内层次数 = n/i（随外层变化），必须逐层求和，不能直接 n×n 相乘。

## 完整知识点梳理

### 调和级数循环（经典考型）

| 循环形式 | 内层次数 | 总次数 | 复杂度 |
| --- | --- | --- | --- |
| `i++` 外层，`j += i` 内层 | ⌊n/i⌋ | Σ n/i = n·H(n) | **O(n log n)** |
| `i++` 外层，`j = i` 起步 `j++` | n − i + 1 | Σ(n−i+1) ≈ n²/2 | O(n²) |
| `i++` 外层，`j < i` | i | Σi ≈ n²/2 | O(n²) |
| `i++` 外层，`j += 2i` | ⌊n/(2i)⌋ | (n/2)·H(n) | O(n log n)（常数不影响） |

### 调和级数关键结论

- H(n) = 1 + 1/2 + 1/3 + … + 1/n ≈ ln n + γ（γ ≈ 0.577）
- **H(n) = O(log n)**，这是「步长依赖型」循环的核心数学工具
- 经典应用：埃拉托斯特尼筛法（素数筛）的复杂度就是 O(n log log n)——同一套求和逻辑，只是外层只遍历素数

### 判定流程更新（在原有三步上加一步）

1. 看内层是否依赖外层变量 → 依赖则必须求和
2. 写出内层次数关于 i 的表达式（如 n/i、i、i²）
3. 求和：等差 → n²，等比 → n，**调和 → n log n**，平方和 → n³
4. **看到 j += i 或「步长与外层相关」时，优先想调和级数 n log n**

### 一句话记忆

> **步长是 i，次数是 n/i，求和 n·H(n) ≈ n log n** ——「筛法套路」，看到 j += i 就想调和级数。

## 复刷清单

### 举一反三 5 题

1. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = i; j <= n; j += i)
           count++;
   ```
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(n√n)
   **答案：B**。内层次数 ⌊n/i⌋，Σn/i = n·H(n) ≈ n log n。

2. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = i; j <= n; j++)
           count++;
   ```
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(n√n)
   **答案：C**。内层步长为 1（不是 j += i），次数 n−i+1，等差求和 ≈ n²/2。

3. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= n; j += i)
           count++;
   ```
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(n log log n)
   **答案：B**。内层从 1 开始、步长 i，次数 ⌈n/i⌉ ≈ n/i，求和仍是 n·H(n)。

4. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = i; j <= n; j += 2 * i)
           count++;
   ```
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(n√n)
   **答案：B**。次数 ⌊n/(2i)⌋ ≈ n/(2i)，求和 (n/2)·H(n)，常数不影响量级。

5. 【单选】关于调和级数 H(n) = 1 + 1/2 + … + 1/n，下列说法正确的是（ ）。
   A. H(n) = O(1)　B. H(n) = O(√n)　C. H(n) = O(log n)　D. H(n) = O(n)
   **答案：C**。H(n) ≈ ln n + γ，量级 O(log n)。这是「j += i」型循环的数学基础。

### 历年真题风格练习

1. 【统考风格】下列程序段的时间复杂度是（ ）。
   ```c
   int count = 0;
   for (int i = 1; i <= n; i++)
       for (int j = 1; j <= n; j += i)
           count++;
   ```
   A. O(n)　B. O(n log₂ n)　C. O(n²)　D. O(n log log n)
   **答案：B**。标准调和级数循环，Σ⌈n/i⌉ = O(n log n)。

2. 【统考风格】埃拉托斯特尼筛法（标记所有素数的倍数）的时间复杂度是（ ）。
   A. O(n)　B. O(n log n)　C. O(n log log n)　D. O(n²)
   **答案：C**。Σ(对每个素数 p 有 n/p 次) = n·Σ(1/p)（仅素数）= n log log n。注意与全遍历版本（j += i，对所有 i）的 O(n log n) 区分。

3. 【统考风格】下列四个循环中，时间复杂度最高的是（ ）。
   甲：`for(i=1;i<=n;i++) for(j=i;j<=n;j+=i)`
   乙：`for(i=1;i<=n;i++) for(j=1;j<=n;j++)`
   丙：`for(i=1;i<=n;i*=2) for(j=1;j<=i;j++)`
   丁：`for(i=1;i<=n;i++) for(j=1;j<=i;j++)`
   A. 甲　B. 乙　C. 丙　D. 丁
   **答案：B**。乙是 n×n = n²（最高）；甲 n log n；丙 ≈ 2n；丁 ≈ n²/2（与乙同阶但乙精确次数更高，量级相同——若按量级则 B 与 D 同为 O(n²)，单选取精确次数最大者 B）。
