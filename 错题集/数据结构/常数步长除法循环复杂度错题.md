# 常数步长除法循环复杂度错题

- 正确答案：B（O(n)）

## 题目

设 n 为不小于 2 的整数，i、j 均按整数运算。下列程序段的时间复杂度是（ ）。

```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= n; j += n / 2)
        count++;
```

A. O(log₂ n)　B. O(n)　C. O(n log₂ n)　D. O(n²)

## 根因分析

我一眼看到两层嵌套就直接乘 n × n 选了 D，忽略了**内层步长是 n / 2，与 n 同阶**：j 从 1 出发，第 1 轮 j += n/2 → 约 n/2，第 2 轮 j += n/2 → 约 n，第 3 轮 j 超过 n 退出。内层实际只执行 **2~3 次（常数次）**，不是 n 次。总次数 ≈ n × 3 = O(n)。

## 完整知识点梳理

嵌套循环复杂度的判定顺序：**先看内层每轮执行多少次，再乘外层次数**，不要被「两层」的外形带偏。

| 内层步长 | 内层次数 | 外层 n 次 → 总复杂度 |
| --- | --- | --- |
| `j++`（线性） | n 次 | O(n²) |
| `j *= 2`（对数） | log₂ n 次 | O(n log n) |
| `j += i`（调和，依赖 i） | n/i 次 | Σn/i = O(n log n) |
| `j += n/2`（常数次，本题） | 2~3 次 | **O(n)** |
| `j += n`（1 次） | 1 次 | O(n) |

**关键判定法则**：
1. 内层步长是外层变量的函数 → 执行次数随 i 变化，需逐层求和。
2. 内层步长是 n 的固定比例 → 每轮执行**常数次**，总复杂度退化为外层次数 O(n)。
3. 「两层嵌套 ≠ n²」，必须看内层真实执行次数。

**记忆口诀**：

> **「步长同阶 n，内层常数次」**——看到 `j += n/2` 就想「两步跨完 n」，总量 = 外层 n 次 × 常数 = O(n)。

## 复刷清单

### 举一反三 5 题

1. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= n; j += n) count++;
   ```
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(n³)
   **答案：A**。内层步长 n，每轮只执行 1 次，总 O(n)。

2. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= n; j += n / 2) count++;
   ```
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(n³)
   **答案：A**。j 依次为 1 → 1+n/2 → 1+n，第 3 次退出，内层常数次，总 O(n)。

3. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= n; j *= 2) count++;
   ```
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(n³)
   **答案：B**。对数步长 log₂ n 次，总 n·log₂ n。

4. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= n; j += i) count++;
   ```
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(n³)
   **答案：B**。调和级数 Σ n/i = n·H(n) ≈ n·ln n。

5. 【单选】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= n; j += n / 4) count++;
   ```
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(n³)
   **答案：A**。j 每次跨 n/4，内层执行 4~5 次，仍是常数，总 O(n)。

### 历年真题风格练习

1. 【统考风格】下列程序段的时间复杂度是（ ）。
   ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= n; j += n / 2 + 1) count++;
   ```
   A. O(n)　B. O(n log n)　C. O(n²)　D. O(n³)
   **答案：A**。内层步长 ≈ n/2，常数次后退出，总 O(n)。

2. 【统考风格】下列关于嵌套循环复杂度的说法，正确的是（ ）。
   A. 两层嵌套循环的复杂度一定是 O(n²)
   B. 内层步长是外层变量的函数时，需逐层求和
   C. 内层步长为 n 的固定比例时，内层执行次数是 O(n)
   D. 内层次数固定时，总复杂度由外层循环决定
   **答案：D**。内层常数次时总量 = 外层次数 × 常数；B 虽表述正确，但本题强调「步长同阶→常数次→总量由外层决定」，D 是对实际判定顺序的准确概括（A、C 显然错误）。

3. 【统考风格】设 n ≥ 2，下列程序段中总复杂度为 O(n) 的是（ ）。
   Ⅰ. `for(i=1;i<=n;i++) for(j=1;j<=n;j+=n/2)`
   Ⅱ. `for(i=1;i<=n;i++) for(j=1;j<=n;j+=n)`
   Ⅲ. `for(i=1;i<=n;i++) for(j=1;j<=n;j++)`
   A. 仅Ⅰ　B. 仅Ⅱ　C. Ⅰ和Ⅱ　D. Ⅰ、Ⅱ和Ⅲ
   **答案：C**。Ⅰ内层约 2~3 次、Ⅱ内层 1 次，均为常数；Ⅲ内层 n 次 → O(n²)。
