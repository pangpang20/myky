## 题目

$$\lim_{n\to\infty}\left(\frac{n-2}{n+1}\right)^n = \underline{\qquad}$$

## 解答

这是 $1^\infty$ 型极限，凑第二个重要极限 $\lim(1+\tfrac1x)^x=e$：

$$\left(\frac{n-2}{n+1}\right)^n = \left(1+\frac{-3}{n+1}\right)^n$$

令指数凑型：

$$= \left(1+\frac{-3}{n+1}\right)^{\frac{n+1}{-3}\cdot\frac{-3n}{n+1}} = \left[\left(1+\frac{-3}{n+1}\right)^{\frac{n+1}{-3}}\right]^{\frac{-3n}{n+1}}$$

方括号内 $\to e$，指数 $\dfrac{-3n}{n+1}\to -3$，故

$$\lim_{n\to\infty}\left(\frac{n-2}{n+1}\right)^n = e^{-3} = \frac{1}{e^3}$$

**更快的方法**（取对数）：

$$\ln L = \lim_{n\to\infty} n\ln\frac{n-2}{n+1} = \lim_{n\to\infty} n\ln\left(1-\frac{3}{n+1}\right) \approx \lim_{n\to\infty} n\cdot\left(-\frac{3}{n+1}\right) = -3$$

所以 $L=e^{-3}$。

## 代数验证（独立方法）

数值实验（直接计算 $(n-2)/(n+1)$ 的 $n$ 次方）：

## 根因分析

未作答。核心是不熟悉 $1^\infty$ 型极限的标准处理套路：把底数写成 $1+u(n)$（$u(n)\to0$），再把指数凑成 $\dfrac{1}{u(n)}\cdot(\text{原指数}\cdot u(n))$，利用 $\lim(1+u)^{1/u}=e$ 化为「$e$ 的指数」求极限；或两边取对数化为 $\infty\cdot0$ 型处理。

## 完整知识点梳理

**第二个重要极限**：$\lim_{x\to\infty}\left(1+\dfrac1x\right)^x=e$，等价形式 $\lim_{u\to0}(1+u)^{1/u}=e$。

**$1^\infty$ 型标准套路**（设 $\lim f(n)=1$，$\lim g(n)=\infty$）：

$$\lim f(n)^{g(n)} = e^{\lim g(n)\,[f(n)-1]}$$

推导：$f^g = e^{g\ln f}$，$\ln f = \ln(1+(f-1))\sim f-1$（$f\to1$ 时），故指数 $\to\lim g(f-1)$。

**本题代入**：$f=\dfrac{n-2}{n+1}$，$f-1=\dfrac{-3}{n+1}$，$g=n$，$g(f-1)=\dfrac{-3n}{n+1}\to-3$，故极限为 $e^{-3}$。

**常用结论**（同型速查）：

| 题型 | 极限 |
| --- | --- |
| $\left(\dfrac{n+a}{n+b}\right)^n$ | $e^{a-b}$ |
| $\left(\dfrac{n-2}{n+1}\right)^n$ | $e^{-3}$（$a=-2,b=1$） |
| $\left(1+\dfrac{k}{n}\right)^n$ | $e^{k}$ |

**记忆口诀**：

> **「一的无穷次方，底数减一乘指数，算出多少就是 $e$ 的多少次方。」**

**易错点**：
1. 底数减一算错符号：$\dfrac{n-2}{n+1}-1=\dfrac{-3}{n+1}$，不是 $\dfrac{3}{n+1}$。
2. 忘记「底数减一乘指数」要取极限，直接写 $e^{-3n}$。
3. 与 $\left(1+\dfrac{k}{n}\right)^n=e^k$ 混淆，套错分子。
4. 写成 $e^3$（漏负号）。
