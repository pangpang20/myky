# 导数积分换元错题

## 错题信息

- 科目：高等数学（积分·不定积分与定积分换元）

- 正确答案：$\int f'(x)\,dx = f(x)+C$；$\displaystyle\int_a^b f'(2x)\,dx = \frac{f(2b)-f(2a)}{2}$
- 状态：待复刷（艾宾浩斯第 1 轮）

## 题目

$$\int f'(x)\,\mathrm{d}x = \underline{\qquad},\qquad \int_a^b f'(2x)\,\mathrm{d}x = \underline{\qquad}\quad (a\neq b)$$

## 解答

**第一空**（不定积分）：由定义 $[f(x)]'=f'(x)$，故

$$\int f'(x)\,\mathrm{d}x = f(x)+C$$

**第二空**（定积分换元）：令 $u=2x$，则 $\mathrm{d}u=2\,\mathrm{d}x$，$\mathrm{d}x=\dfrac{1}{2}\mathrm{d}u$；$x=a\to u=2a$，$x=b\to u=2b$：

$$\int_a^b f'(2x)\,\mathrm{d}x = \frac{1}{2}\int_{2a}^{2b} f'(u)\,\mathrm{d}u = \frac{1}{2}\Big[f(u)\Big]_{2a}^{2b} = \frac{f(2b)-f(2a)}{2}$$

**关键**：换元后 $\mathrm{d}x$ 要乘 $\dfrac{1}{2}$，上限下限也要换成 $2a,2b$——两个地方都容易漏。

## 代数验证（独立方法）

取 $f(x)=x^3$（则 $f'(u)=3u^2$），$a=0.7$，$b=2.3$：

$$\int_a^b f'(2x)\,\mathrm{d}x = \int_{0.7}^{2.3} 12x^2\,\mathrm{d}x = 4x^3\Big|_{0.7}^{2.3} = 4(2.3^3-0.7^3)$$

公式值 $\dfrac{f(2b)-f(2a)}{2}=\dfrac{(4.6)^3-(1.4)^3}{2}$，两者相等（Simpson 数值积分 20000 步验证，误差 <10⁻⁸）。✅

## 根因分析

未作答。核心是没掌握「复合函数导数的积分」必须**换元**：$f'(2x)$ 对 $x$ 积分时，$\mathrm{d}(2x)=2\,\mathrm{d}x$，即 $\mathrm{d}x=\dfrac{1}{2}\mathrm{d}(2x)$，因此 $\int f'(2x)\,\mathrm{d}x=\dfrac{1}{2}f(2x)+C$（不定积分）或 $\dfrac{f(2b)-f(2a)}{2}$（定积分）。最容易漏的是系数 $\dfrac{1}{2}$。

## 完整知识点梳理

**不定积分基本公式**：$\displaystyle\int F'(x)\,\mathrm{d}x = F(x)+C$。特别地 $\int f'(x)\,\mathrm{d}x=f(x)+C$。

**换元法（凑微分）**：设 $u=2x$，则 $\mathrm{d}u=2\,\mathrm{d}x$。一般地，对 $f'(kx)$（$k\neq0$ 常数）：

$$\int f'(kx)\,\mathrm{d}x = \frac{1}{k}f(kx)+C$$

推导：$\left[\dfrac{1}{k}f(kx)\right]' = \dfrac{1}{k}\cdot f'(kx)\cdot k = f'(kx)$。✓

**定积分换元（上下限同步变换）**：

$$\int_a^b f'(kx)\,\mathrm{d}x = \frac{f(kb)-f(ka)}{k}$$

**易错点**：
1. 忘记除以 $k$：误写 $\int_a^b f'(2x)\,\mathrm{d}x = f(2b)-f(2a)$。
2. 定积分换元后忘换上下限：误写 $\int_a^b f'(2x)\,\mathrm{d}x = \dfrac{1}{2}[f(2x)]_a^b$。
3. 不定积分漏常数 $C$。
4. 把 $\int f'(2x)\,\mathrm{d}x$ 当成 $\int f'(x)\,\mathrm{d}x=f(x)+C$ 直接套（漏了 $2x$）。

**记忆口诀**：

> **「导数里面有 $kx$，积出来要除以 $k$；定积分还得换上下限。」**

1. 【单选】$\displaystyle\int_0^1 f'(3x)\,\mathrm{d}x=$（ ）。A. $f(3)-f(0)$　B. $\dfrac{f(3)-f(0)}{3}$　C. $3[f(3)-f(0)]$　D. $\dfrac{f(1)-f(0)}{3}$　**答案：B**。
2. 【单选】设 $f(x)=e^x$，则 $\displaystyle\int_0^1 f'(2x)\,\mathrm{d}x=$（ ）。A. $e^2-1$　B. $\dfrac{e^2-1}{2}$　C. $e-1$　D. $\dfrac{e-1}{2}$　**答案：B**。
3. 【单选】设 $f'(x)=\cos x$，则 $\displaystyle\int_0^{\pi} f'\left(\frac{x}{2}\right)\mathrm{d}x=$（ ）。A. $1$　B. $2$　C. $0$　D. $4$　**答案：B**（$\int_0^\pi\cos\frac{x}{2}\,\mathrm{d}x=2\sin\frac{x}{2}\Big|_0^\pi=2$）。
4. 【单选】设 $f(x)=\ln x$，则 $\displaystyle\int_1^2 f'\left(\frac{x}{2}\right)\mathrm{d}x=$（ ）。A. $2\ln 2$　B. $\ln 2$　C. $-\ln 2$　D. $\dfrac{\ln 2}{2}$　**答案：A**（$f'(x/2)=\dfrac{1}{x/2}\cdot\frac{1}{2}=\dfrac1x$，$\int_1^2\dfrac1x\,\mathrm{d}x=\ln2$）。
5. 【单选】设 $k\neq0$ 为常数，则 $\displaystyle\int_a^b f'(kx)\,\mathrm{d}x=$（ ）。A. $f(kb)-f(ka)$　B. $k[f(kb)-f(ka)]$　C. $\dfrac{f(kb)-f(ka)}{k}$　D. $\dfrac{f(b)-f(a)}{k}$　**答案：C**。
