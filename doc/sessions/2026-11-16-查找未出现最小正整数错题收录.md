## 实现功能

1. 收录用户发送的错题（2018-41 统考真题，未作答）。
2. 新建档案 `错题集/数据结构/查找未出现的最小正整数错题.md`：
   - 基本设计思想：答案必在 `1~n+1`，长度 n+1 标记数组，只标记 `1..n` 范围的值；
   - C 参考算法（malloc/free、范围过滤、全出现返回 n+1）；
   - 时间 O(n)、空间 O(n) 分析 + 四种解法对比表（含 O(1) 空间原地归位变式）；
   - 根因分析 7 条、知识点梳理（辅助数组标记模板表、与 2015-41 的关联）；
   - 复刷 5 题 + 真题风格 3 题；
   - 二次验证记录 + 复习记录。
3. 通过 `register-wrong-question.mjs` + `payload-ds-miss-min.json` 双端登记：quiz 8 题（`ds-miss1~5` + 3 道真题）、艾宾浩斯第 1 轮 5 题。
4. 更新算法索引：2018-41 行与「辅助数组标记」行均标记为已收录，计数 `3/19 → 4/19`。

## 二次验证

- 大模型交叉核对（glm-5.3）：本地 API 代理 `https://127.0.0.1:3800/v1` 直接调用 GLM-5.3 独立作答原题 + 8 题，9 题结论全部一致（原题 O(n)/O(n)；1=B、2=C、3=B、4=B、5=D、真题1=A、真题2=A、真题3=A）。✅ 无分歧。
- 分歧排查记录：真题 2 曾把原地归位的时间复杂度选项设为 `O(n²) 最坏`，GLM-5.3 与代数分析均确认每次交换至少归位一个元素、总交换 ≤ n，故为 O(n)，已在档案中补记该结论。
