# 2026-11-16 数组乘积最大值 calMulMax 错题收录

## 需求

用户发送题目截图：`calMulMax(int A[], int res[], int n)`，`res[i] = max(A[i]·A[j])`（`0≤i≤j≤n-1`），样例 `A={1,4,-9,6}` → `res={6,24,81,36}`。未作答，按流程收录。

## 解法

从右往左一次扫描，维护后缀最大值 `sufMax` 与后缀最小值 `sufMin`：
- `A[i] ≥ 0` → `res[i] = A[i] * sufMax`
- `A[i] < 0` → `res[i] = A[i] * sufMin`
- 因 `j` 可等于 `i`，必须**先更新极值再计算** `res[i]`

时间 O(n)、空间 O(1)。

## 排查过程

初次按「`i≠j`」理解公式，算出 {4,4,0,0}，与题面 {6,24,81,36} 不符。再按「`j>i`」算出 {6,24,-54,undefined}，仍不符。最终确认题面是 **`i ≤ j`** 闭区间（含自身），`res[2]=(-9)·(-9)=81` 才成立。
