# 2026-11-15 4318 防止误清服务端进度

## 问题与修复
- 用户反馈：做了几题后进度被清空。
- 根因：`startQuiz()` 在开新一轮时无条件调用 `clearProgress()`，会清掉服务端已保存的进度。
- 修复：`startQuiz` 先从服务端 `loadProgress()`，只有确认没有任何保存进度时才允许 `clearProgress()`；有保存进度时绝不清理。

## 验证
- 手动 API 实测：`POST /api/progress` 保存 → `GET` 返回正确；空 `ids` 清空 → `GET` 返回 null，逻辑正常。
- 测试全部通过（quiz 50 题、wrong-book 19 份、east8-time、stats-drill 含新增 2 项断言）。
- 服务已重启。
