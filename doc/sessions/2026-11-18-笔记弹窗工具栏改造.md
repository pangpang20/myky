# 笔记弹窗工具栏改造

## 实现内容

用户要求：去掉标题栏右侧的「− ＋ 复位」缩放按钮组，改为在关闭按钮旁加「最大化 / 复原」按钮，美化关闭按钮与左侧标题。

### 改动

- `index.html`
  - 删除 `.note-tools` 按钮组（放大/缩小/复位）相关 HTML 与 CSS。
  - 标题区重构为 `.note-title-wrap`：渐变圆角图标块（📄）+ 标题文本（单行省略号截断）。
  - 右侧新增 `.note-actions`：最大化 `▢`、复原 `❐`、关闭 `✕` 三个图标按钮。
  - 关闭按钮 hover 变为红色（`#ef4444`）白字；其他按钮 hover 提亮边框与背景。
  - 最大化时隐藏「最大化」显示「复原」，由 `.note-maximized` 类控制。
- `app.js`
  - 新增 `maximizeNote()`：记录当前布局到 `noteLayout.__prev`，铺满整个视口。
  - 新增 `restoreNote()`：从 `__prev` 恢复原尺寸位置，并移除 `.note-maximized`。
  - 拖动标题栏时自动退出最大化状态。
  - 原有 Ctrl+滚轮缩放、右下角拖拽调整大小保持不变。

## 测试结果

- 无头浏览器（Playwright + Chrome）实测：
  - `.note-tools` 旧按钮组数量 = 0（已移除）
  - 新按钮均存在：`.note-max`、`.note-restore`、`.note-close`、`.note-ico`
  - 初始状态「复原」按钮 `display: none`，仅显示最大化
  - 点击最大化 → 弹窗铺满 1280×720（与视口一致），「复原」变为 `flex` 显示
  - 点击复原 → 恢复为 760×562
  - 关闭按钮 hover 背景色 `rgb(239, 68, 68)`
- `node 错题集/tests/quiz.test.mjs`：159 题通过。
- `node 错题集/tests/wrong-book.test.mjs`：33 份档案通过。
