# 数据结构算法模型与历年真题索引落地

- 日期：2026-11-16
- 主题：把用户提供的 408 算法复习清单整理为可追溯的本地训练主线索引

## 实现功能

1. 新增 `doc/数据结构算法模型与历年真题索引.md`，含六个栏目：
   - 数组与线性表算法（10 个模型）
   - 链表算法（7 个模型）
   - 查找与排序算法（10 个算法）
   - 树与图的算法（11 个模型）
   - 历年算法设计题主线（2009–2026 共 19 题，含题号、考查内容、对应模型）
   - 其他常考算法（KMP、B 树、B+ 树、折半查找、快速排序、二叉排序树）
2. 每个模型/年份新增「本地错题档案」列，与实际档案文件建立相对链接，避免清单与错题库脱节。
3. `错题集/README.md` 增加「训练主线索引」入口说明。
4. 新增 `错题集/tests/algorithm-index.test.mjs` 结构校验：
   - 六个栏目必须存在；
   - 所有相对链接必须指向真实文件；
   - 标 ✅ 的行必须有链接，标「未收录」的行不得有链接；
   - 摘要「已收录 X / Y 题」中的 X 必须与 ✅ 行数一致。

## 测试结果

- `node 错题集/tests/algorithm-index.test.mjs`：**通过**（8 个链接、3 道已收录）。
- `node 错题集/tests/quiz.test.mjs`：**通过**（103 题）。
- `node 错题集/tests/wrong-book.test.mjs`：**通过**（26 个档案）。
- 测试首次运行发现摘要写成「已收录 4 / 19」但实际只有 3 条历年真题（「有序顺序表去重」非真题，不应计入），已修正为 3/19 后通过。
