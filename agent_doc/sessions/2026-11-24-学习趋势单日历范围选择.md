# 2026-11-24 学习趋势单日历范围选择

## 实现功能
- 用户反馈：上一版「📅 日期范围」弹窗里仍是两个原生 date 输入框，不对；要求「就是在一个弹出的框中可以选择起止时间」——即一个日历网格里直接点选起始/结束两个日期。
- `错题集/ebbinghaus/index.html`：
  - 移除弹窗内 `trendStart`/`trendEnd` 两个独立 date 输入，改为：月份标题（‹ / › 切换）、周一~周日表头、日历格子 `#trendCalendar`、选择提示 + 应用按钮；
  - 新增日历 CSS（disabled / in-range / start / end 高亮）。
- `错题集/ebbinghaus/app.js`：
  - 新增 `calStart/calEnd/calYear/calMonth` 状态；
  - `renderTrendCalendar()` 渲染当月网格，超过今天的日期加 `disabled` 不可点；
  - `pickTrendDate()` 在一个日历内两点式选择：第一次点起始、第二次点结束，若第二次早于起始则自动交换；选中区间高亮；
  - `shiftTrendMonth()` 切换月份；`applyTrendRange()` 应用并强制按天汇总；`clearTrendRange()` 清空日历选点与范围。
  - 保留此前功能：自定义范围 X 轴按天、结束不超过今天、清空恢复默认。
- 更新 `错题集/tests/trend-filter.test.mjs`（18 项，含「不再使用两个独立原生日期输入」「单日历渲染/点选」「超过今天不可选」「可切换月份」）。
