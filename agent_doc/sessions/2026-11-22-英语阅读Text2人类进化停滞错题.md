# 2026-11-22 英语阅读 Text 2 人类进化停滞错题

## 实现内容

- 按用户黄色标记核对 2000 年考研英语 Text 2：15.A、16.B、17.A、18.D；官方答案 CBAD。用户说明黄色可能错误，因此档案逐题记录核对结果：第 15 题确为错题；第 16–18 题标记与官方答案一致，仍纳入同篇文章分题型复刷。

- 更新 4317 的 `quiz/questions.json`、`quiz/knowledge.json`，4318 的 `ebbinghaus/questions.json`、`ebbinghaus/knowledge.json`，以及 SQLite `data/ky.db`。
