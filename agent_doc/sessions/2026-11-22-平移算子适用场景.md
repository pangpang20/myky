# 2026-11-22 平移算子适用场景

## 实现功能
- 用户在 4318 共振例题「用平移算子秒求系数」处问「什么情况可以用」。
- 在 `错题集/高等数学/二阶常系数非齐次线性微分方程错题.md` 的平移公式一般形式后补充「什么时候用平移算子（降阶法）」判定表：
  - $P_m(x)e^{\lambda x}$ 且 $\lambda$ 是特征根（共振）→ 用，设 $y=e^{\lambda x}v$ 得 $v^{(k)}=P_m(x)$ 积分 $k$ 次；
  - $P_m(x)e^{\lambda x}$ 且 $\lambda$ 不是特征根 → 不必用，待定系数法；
  - $e^{\alpha x}(A\cos\beta x+B\sin\beta x)$ → 复数版平移，考研更常直接设特解；
  - 多项式 / $\ln x$ / $\tan x$ 等 → 不适用，用待定系数或常数变易法。
- 一句话总结：只有右端是指数乘多项式且 $\lambda$ 撞特征根时，平移算子才显威力。
- 同步 payload 与双端知识卡 knowledge。
