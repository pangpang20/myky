# 2026-11-24 学习趋势日历日期显示修复

## 实现功能
- 用户反馈单日历弹窗「日期显示不全」。
- 根因：全局样式 `.empty{padding:44px}` 同时命中日历的占位格 `.cal-day.empty`，把空格子撑成 90×90；`repeat(7,1fr)` 列被空格子内容撑破，前 6 列 90px、第 7 列仅 16px，日期被挤出面板，而 `.section{overflow:hidden}` 裁掉超出部分。
- `错题集/ebbinghaus/index.html` 修复：
  - `.cal-week,.cal-grid` 改用 `repeat(7,minmax(0,1fr))`，`.cal-grid` 加 `grid-auto-rows:30px`；
  - `.cal-day` 加 `min-width:0;box-sizing:border-box`；
  - `.cal-day.empty` 显式 `min-width:0;height:30px;padding:0;border:none`，覆盖全局 `.empty` 的 padding。
- 更新 `错题集/tests/trend-filter.test.mjs`（21 项，含 CSS 等宽、空格子约束、覆盖全局 empty padding 的回归断言）。
