# 2026-11-19 考研速记规律与跨行公式修复

## 实现功能
1. 「旋转体体积正弦曲线」错题档案新增「## 考研速记规律（一看就会）」章节，共 7 条规律：
   - 规律 1：选公式只看「绕谁转、怎么切」——四行速判表 + 口诀「绕 x 看 y、绕 y 看 x；给谁用谁、反解难就换壳」
   - 规律 2：上下限永远跟积分变量同字母
   - 规律 3：华里士公式秒算 `sin^n`/`cos^n` 在 `[0,π/2]`（偶带 π/2、奇不带）
   - 规律 4：区间换算（`[0,π]` = 2 倍、`[0,2π]` 偶次 = 4 倍、奇次 = 0，含 sin/cos 对称性差异）
   - 规律 5：奇偶 + 对称区间直接归零（含奇偶识别三条速记）
   - 规律 6：三个高频陷阱对照表
   - 规律 7：考场 30 秒三步速判流程
2. 修复图片说明里 LaTeX 反斜杠丢失：`$r=sin x+1$` → `$r=\sin x+1$`，`$mathrm{d}V=pi r^{2},mathrm{d}x$` → `$\mathrm{d}V=\pi r^{2}\,\mathrm{d}x$`。
