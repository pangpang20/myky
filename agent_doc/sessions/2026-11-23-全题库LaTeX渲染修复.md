# 2026-11-23 全题库 LaTeX 渲染修复

## 实现功能
- 用户反馈 4318 题目选项中出现 `(C_1+C_2x)e^{x}+ rac14(x-1)e^{-x}` 这类 `rac14` 外露、KaTeX 渲染失败。
- 根因：上一轮生成 ode2 payload 时，`\frac` 的 `\f` 在写入过程中被当成换页符（charCode 12），`frac` 变成控制符 + `rac14`；另有 `e^{lambda x}`、`Rightarrow` 缺反斜杠。
- 系统扫描所有 JSON 题库与知识卡，修复 5 个文件（quiz/ebbinghaus 的 questions/knowledge + payload-ode2）：
  - 控制符还原为 `\frac{1}{4}` 等正确命令；
  - `e^{lambda}` → `e^{\lambda}`，`lambda=` → `\lambda=`，`xRightarrow` → `x\Rightarrow`；
  - 清理 `fracrac` 畸形命令。
- 新增回归测试 `错题集/tests/latex-integrity.test.mjs`（13 项）：扫描 4 个题库/知识卡文件，断言无控制字符、无 fracr 畸形、无裸 lambda，覆盖 5624 个字符串字段。
